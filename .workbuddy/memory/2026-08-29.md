## 修复 GetSession/DeleteExpiredSessions 过期判断的真实 bug

- 根因：`expires_at` 列是 `DATETIME` 亲和类型，modernc/SQLite 会把插入的 `"2006-01-02 15:04:05"` 规范化为 `"2006-01-02T15:04:05Z"`；而 `GetSession` 用空格格式字符串做 `expiresAt < time.Now().Format("2006-01-02 15:04:05")` 比较，'T'(0x54) > 空格(0x20) 导致过期判定永远失效。
- 修复：改为按 `time.Time` 解析比较（优先 RFC3339），`DeleteExpiredSessions` 的 SQL 比较值也改用 `time.RFC3339`。该 bug 由新加的 `TestExpiredSession` 暴露。
- 注意：沙箱 `time.Now()` 非单调，测试过期场景须用固定过去时间点（如 `"2000-01-01T00:00:00Z"`），不能用 `time.Now().Add(-1h)`。
